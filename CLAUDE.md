## Agent skills

### Issue tracker

Issues are tracked as GitHub Issues in this repo (`github.com/MAOFILHO/MLOps-Projects`), via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles use their default label strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context layout: a root `CONTEXT-MAP.md` points to a `CONTEXT.md` per top-level project folder (this is a monorepo of self-contained projects, not a shared `src/` tree). See `docs/agents/domain.md`.
